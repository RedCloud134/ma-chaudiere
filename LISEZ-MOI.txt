MA CHAUDIÈRE MAZOUT — PWA 0.2

1. ESSAI SUR PC : ouvrir index.html avec Chrome ou Edge. Certaines fonctions (installation, météo, stockage) peuvent être restreintes en mode fichier local.
2. MISE EN LIGNE : créer un dépôt GitHub PUBLIC, puis déposer à la racine les fichiers contenus dans ce dossier (et non le ZIP). Dans Settings > Pages > Build and deployment, choisir Deploy from a branch, branche main et dossier / (root), puis Save. Patienter jusqu'à obtenir l'adresse HTTPS fournie par GitHub Pages.
3. SUR SAMSUNG : ouvrir cette adresse HTTPS dans Chrome, menu ⋮ > Ajouter à l'écran d'accueil > Installer (si proposé).
4. Les relevés restent sur chaque appareil, dans le navigateur/PWA ; GitHub Pages ne reçoit pas les relevés. L'adresse du site est publique : n'y mettre aucune donnée personnelle. L'application contacte Open-Meteo pour les températures.
5. Exporter régulièrement une sauvegarde JSON. Ne pas effacer les données du navigateur sans sauvegarde. Les données ne se synchronisent pas entre téléphones.
6. IMPORTANT : la v0.2 utilise un stockage séparé de la v0.1. Une sauvegarde v0.1 n'est pas importable automatiquement. Conserver l'ancienne application et son JSON pour migration ultérieure.
7. Stock initial de 920 L : estimation provisoire, car la mesure de 46 cm date du 20/10 et le compteur n'a été posé que le 27/10. Corriger le stock avec une nouvelle mesure datée. Les 500 L livrés le 20/10 sont déjà inclus dans les 920 L : ne pas les ajouter à nouveau à une date postérieure.
8. La date du compteur initial 27/10 à 20:00 est indicative : l'heure exacte n'a pas été communiquée.
