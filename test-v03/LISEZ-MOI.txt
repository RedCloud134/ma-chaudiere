Ma Chaudière — V0.3 Quotidienne (2026-11-11)
=========================================

Cette archive remplace les fichiers du dossier test-v03 sur GitHub Pages.

Objectif de cette version :
- conserver le moteur de calcul actuellement validé ;
- proposer une présentation suffisamment propre pour un usage quotidien ;
- garder les fonctions utiles : relevés, livraisons, corrections, débit,
  historique, sauvegarde/restauration JSON et export CSV.

Améliorations principales :
- Habillage plus "terrain" pour un usage courant.
- Thème Bronze par défaut.
- Jauge de réserve avec seuil visuel de commande mazout.
- Couleur dynamique de la jauge :
  * vert si réserve >= 50 %
  * orange si réserve < 50 %
  * rouge si stock <= 350 L
- Message d’état adapté à une utilisation quotidienne.

Compatibilité :
- Le stockage local V0.3 déjà présent dans le navigateur est conservé.
- Import JSON V0.2 / V0.3 toujours accepté si valide.
- La V0.2 reste séparée.

Conseil :
- faire une sauvegarde JSON régulière, surtout avant une série d’essais.
